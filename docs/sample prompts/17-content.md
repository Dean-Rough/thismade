# shopface Working Memory

## Brand and offer decisions

- The approved brand system is direct, technical, credible and Scottish-first. Its core language includes: “Better sites. Before the pitch.”
- Use a dark technical visual world with lime emphasis; keep copy short, confident and plain-spoken.
- The first offer is **Website + Care**: `£39/month`; the first ten customers pay `£29/month`; there is a three-month initial term; content changes outside the agreed scope are chargeable.
- Every preview must use verified public facts and be private, clearly unofficial, human-reviewed, unindexed, free of live forms and removed after outreach expires.
- House typography rule: Archivo carries all human-readable copy and IBM Plex Mono carries only system/asserted labels. Every rendered-copy surface uses intentional measures; web headings use progressive `text-wrap: balance`, while email HTML uses constrained text cells as the client-safe fallback. Never add viewport-specific manual line breaks or change approved factual copy to force wrapping.
- Do not introduce performance claims, guarantees, turnaround times, customer stories or unapproved scope details.
